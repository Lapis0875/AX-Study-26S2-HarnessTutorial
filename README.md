# 26년 2학기 겜마루 x 솔브드 연합 AX 스터디 - 실습 자료 저장소

AX스터디를 진행하며, 강의 중 실습에 사용한 코드를 공개하기 위한 저장소입니다.

## 3차시: 나만의 즐겨찾기 웹페이지 (하네스 엔지니어링 실습)

강의 자료에 따른 실습 시작본과 비교용 완료본입니다.

- **학생 앱:** [starter/](starter/README.md) — 이 폴더를 코딩 도구에서 열고 실습을 진행합니다.
- 정답 앱: [starter-complete/](starter-complete/README.md) — 이 폴더는 실습을 마친 후 자신의 결과물을 점검해볼 수 있는 경로입니다.

### 실행 방법 (starter/)

> 이 git 저장소를 clone했다고 가정하고 안내합니다.

저장소 root에서 터미널을 실행하고, 다음 순서대로 명령어를 실행합니다.

```sh
cd starter # starter 폴더로 이동합니다.
npm ci
npm run dev
```

이후 브라우저에서 `http://127.0.0.1:5173`을 엽니다. 같은 주소를 다시 추가하면 별도 항목이 저장되는 시작본입니다.
학생 배포 ZIP에는 `starter/`만 포함합니다. 완료본은 `starter-complete/`에서 별도로 실행합니다.
완료본도 같은 브라우저·접속 주소에서는 시작본의 저장 자료를 읽으므로, 비교 전 자료 보존 여부를 확인합니다.
