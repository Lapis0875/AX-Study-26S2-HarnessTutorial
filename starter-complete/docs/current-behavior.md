# 완료본에서 관찰할 동작

최초 실행 또는 확인 후 초기화하면 U1 한 항목으로 시작합니다.

```text
U1 = https://example.com/read-later/article-1
제목 = 주말에 읽을 글
```

1. 제목 `다시 읽을 글`과 U1을 제출합니다.
2. 목록과 실제 저장 자료는 1개를 유지합니다. 기존 제목·URL·ID·순서가 바뀌지 않습니다.
3. `이미 저장된 웹주소입니다.` 안내가 표시됩니다. 입력값은 유지하고 웹주소란에 초점을 둡니다.
4. 반복 제출·새로고침 후에도 새 중복이 생기지 않습니다.
5. U2 `https://example.com/read-later/video-2`와 제목 `나중에 볼 영상`을 제출하면 2개로 늘어납니다.
6. 새 URL 저장 성공 시 `저장했습니다.`를 표시하고 입력란을 비우며 웹주소란에 초점을 둡니다.

비교 기준은 양끝 공백을 제거한 URL 문자열의 완전 일치입니다. 제목은 중복 판단 기준이 아닙니다.
과거 자료에 같은 URL의 항목이 여러 개 있어도 그대로 읽고 표시합니다. 새로운 중복만 차단합니다.
저장 키와 스키마는 시작본과 같은 `ax-study:l03:bookmarks:v1`, `{ version: 1, items: [...] }`입니다.
예시 URL은 교육용 문자열이며 저장할 때 사이트의 내용을 요청하지 않습니다.
