# 시작본과 완료본 비교하기

완료본은 별도 `starter-complete/` 폴더에서 엽니다. 학생의 시작본 변경을 덮어쓰지 않습니다.

1. README의 실행 방법으로 완료본을 실행합니다. 같은 포트를 쓰는 시작본 서버는 먼저 종료합니다.
2. 기존 자료 보존이 필요하면 별도 브라우저 프로필을 사용합니다. 초기화는 영향을 읽고 확인한 뒤에만 합니다.
3. 초기 U1 한 항목에서 `다시 읽을 글` 제목과 U1을 제출합니다.
4. 실제 저장 자료와 목록이 1개인지, 기존 제목·주소·ID가 보존되는지 확인합니다.
5. 중복 안내, 두 입력값 유지, 웹주소란 초점 이동을 확인합니다.
6. 같은 입력을 반복 제출하고 새로고침해도 새 중복이 생기지 않는지 확인합니다.
7. U2와 `나중에 볼 영상` 제목을 제출하면 2개가 되고 일반 성공·입력 비움·주소 초점이 적용되는지 확인합니다.
8. 새로고침·새 탭 링크·필수 입력·잘못된 주소 오류·초기화 취소를 확인합니다.
9. 기본·목표·중복 회귀 검사를 실행하고 `starter/`의 T01·T03 실패와 완료본 통과를 비교합니다.
10. `src/bookmarks.js`와 `src/app.js`의 차이가 중복 차단·안내·입력 처리에 집중되어 있는지 읽습니다.

과거 중복 자료는 그대로 유지하며 자동 정리하지 않습니다.
저장 오류를 만들려고 실제 사용자 데이터를 손상시키거나 브라우저 전체 데이터를 지우지 않습니다.
구현, 실행한 검사, 화면 확인, 미실행 항목과 남은 문제를 구분해 기록합니다.
