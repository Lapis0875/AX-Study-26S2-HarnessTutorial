# 개선 요구사항 R1~R4

| ID | 요구사항 | 확인 기준 |
| --- | --- | --- |
| R1 | 같은 주소의 새로운 중복 추가 차단 | U1 재입력 후 실제 저장 자료와 목록 수가 늘지 않음 |
| R2 | 기존 자료 보존 | 기존 제목·주소·ID를 덮어쓰거나 삭제하지 않음 |
| R3 | 중복 안내 | 일반 저장 성공과 구분하여 이미 저장된 주소임을 알림 |
| R4 | 새로운 주소 추가 유지 | U2와 같은 다른 주소는 한 항목 추가됨 |

주소 판단은 양끝 공백을 제거한 **저장 문자열의 완전 일치**입니다. 제목은 비교 기준이 아닙니다.
슬래시, 프로토콜, 대소문자, 쿼리 매개변수를 별도로 통합하지 않습니다.
과거에 쌓인 중복도 임의 삭제·병합하지 않습니다. 화면에서만 숨기는 것으로 R1을 충족할 수 없습니다.

기존 입력·저장·초기화·링크 동작을 유지합니다. 검색·태그·편집·삭제·자동 수집·AI API는 이번 범위 밖입니다.
완료본에서는 `이미 저장된 웹주소입니다.`를 기존 안내 영역에 표시합니다.
중복 차단 시 두 입력값을 유지하고 웹주소 입력란으로 초점을 이동합니다.
