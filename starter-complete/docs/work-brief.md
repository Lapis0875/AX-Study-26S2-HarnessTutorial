# L03 완료본의 실습 요청 근거

아래는 완료본이 해결하는 시작본의 실습 요청입니다. 완료본의 현재 동작은 `current-behavior.md`를 확인합니다.
이 기준 요청서는 L02를 마치지 못한 학생도 사용할 수 있습니다. 자신의 요청서와 조합할 때 출처와 수정 부분을 구분합니다.

## 요청

현재 즐겨찾기 앱에서 같은 웹주소를 다시 저장하면 항목이 늘어납니다.
`requirements.md`의 R1~R4에 따라 새 중복 추가를 막고 중복임을 안내하도록 코드를 변경하고 실행·검사해 주세요.
기존 제목·주소·ID는 보존하고 새 주소 추가는 계속 가능해야 합니다.

## 근거와 작업 경계

- `current-behavior.md`: M01에 대응하는 현재 중복 재현 사실
- `requirements.md`: M02에 대응하는 개선 목표
- 기존 제목을 새 제목으로 덮어쓰자는 M03 의견은 채택하지 않았습니다.
- L02의 문서 작성 전용 작업은 끝났습니다. L03에서는 이 범위의 코드 변경·실행·검사를 수행합니다.
- 입력·저장·화면 정책은 `implementation-decisions.md`를 따릅니다.

## 완료 확인

기본 검사가 계속 통과하고 T01~T04가 모두 통과해야 합니다.
브라우저에서 U1 재입력, 기존 자료 보존, 중복 안내, U2 추가, 새로고침, 초기화를 확인합니다.
중복 안내 문구와 차단 시 입력값·초점 처리는 결정한 내용을 기록합니다.
최종 보고에는 변경 파일, 실제 실행한 검사, 화면 확인, 미실행 항목과 남은 문제를 구분합니다.
