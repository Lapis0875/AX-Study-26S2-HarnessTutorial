# 현재 관찰할 동작

처음 실행하거나 명시적으로 초기화하면 아래 한 항목이 있습니다.

```text
U1 = https://example.com/read-later/article-1
제목 = 주말에 읽을 글
```

1. `다시 읽을 글`이라는 제목과 U1을 추가합니다.
2. 목록과 실제 저장 자료가 1개에서 2개가 됩니다. 두 제목과 같은 주소가 모두 남습니다.
3. 일반 안내 `저장했습니다.`가 표시되고 입력칸이 비워집니다. 웹주소에 초점이 갑니다.
4. 새로고침해도 두 항목의 ID·제목·주소·순서가 유지됩니다.
5. 다시 제출하면 세 번째 별도 항목이 생깁니다.

주소 예시는 교육용 비교 문자열입니다. 실제 글이나 영상이 존재한다는 뜻이 아닙니다.
저장할 때 해당 사이트를 요청하지 않습니다. 현재 문제는 새 중복 추가이며, 기존 제목을 덮어쓰는 동작이 아닙니다.

`localStorage` 키 `ax-study:l03:bookmarks:v1`의 `{ version: 1, items: [...] }`에서 실제 자료를 확인할 수 있습니다.
다른 키나 실제 브라우저 즐겨찾기를 수정할 필요가 없습니다.
